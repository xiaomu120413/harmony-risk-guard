# 风险守卫（Risk Guard）产品说明 v1.0.0

面向 HarmonyOS PC 的**本地离线操作风险评估工具**：对 Agent 拟执行的操作给出
「可继续 / 需确认 / 应阻止」三档风险建议。

## 1. 产品定位与边界

- **给谁用**：需要在执行前快速判断 Agent 操作风险的个人用户与开发者
- **怎么算**：端侧 MiniRBT-h256 三分类模型（41.2MB，MindSpore Lite 2.7.0），
  CPU 4 线程单次推理约 **9–15ms**（2 线程为 15ms，实测矩阵见下）
  - 推理后端：**CPU**（设备 NPU 存在但当前运行时/公开 API 不支持标准 `.ms`，
    详见 [npu-notes.md](npu-notes.md)）
  - 置信度说明：模型在合成数据上过拟合，概率偏饱和（常见 99%+），仅供参考
- **数据边界**：完全离线，不申请网络权限；输入、推理与历史记录都不离开设备
- **决策边界**：输出只是**风险建议，不构成授权**；涉及不可恢复删除、凭据外发等
  高危操作时，必须由确定性策略引擎独立判断并在不确定时拒绝执行（fail closed）

## 2. 界面导览

应用采用桌面三栏式布局：左侧导航（风险评估 / 历史记录 / 关于），右侧内容区。

### 风险评估（主页面）

左栏为「操作信息」表单：

| 字段 | 说明 | 取值 |
|---|---|---|
| 用户指令 | Agent 要执行的指令原话 | 自由文本 |
| 工具 | 具体操作工具 | 如 `file.delete` / `network.send` |
| 操作目标 | 作用对象类型 | 如 `user_document` / `access_token` |
| 操作范围 | 影响面 | 单个 / 批量 / 递归（可填数量） |
| 授权状态 | 用户是否明确授权 | 已授权 / 不明确 / 已拒绝 |
| 数据分级 | 目标数据敏感度 | 公开 / 内部 / 个人 / 机密 / 绝密 |
| 目的地信任 | 外发目的地可信度 | 可信 / 企业内 / 未知外部 / 不可信外发 |
| 操作可恢复 | 删除/覆盖后能否恢复 | 开关 |
| 存在备份 | 是否有可用备份 | 开关 |

右栏为结果面板：
- 大号决策徽章（绿=可继续，琥珀=需确认，红=应阻止）
- 三类置信度条形图（可继续 / 需确认 / 应阻止）
- 决策建议（ASK 会提示补充授权/确认目的地/恢复条件）
- 固定免责声明

未评估时右栏显示「等待评估」与三档决策图例，帮助新手理解输出。

### 历史记录

- 最近 20 条评估，保存在本机（`preferences`）
- 每条显示：决策徽章、指令摘要、时间、工具→目标、三类分数
- 支持一键清空

### 关于

应用版本、运行平台、网络状态；模型信息（MiniRBT-h256 / 41.2MB / 输入输出 / 推理耗时）；
隐私说明与免责声明；右上角「自检与诊断」入口。

### 自检与诊断（开发验证页）

普通使用无需进入。提供：M2-A 转换器/运行时（MLP）、M2-B 真实模型（MiniRBT）、
M2-C 分词一致性（31 例，含截断）、M2-D 原生 NAPI、M2-F 1000 次基准。

## 3. 使用流程

1. 打开应用（首次使用自动预热模型，约 25ms 加载）
2. 在「风险评估」填写操作信息（默认示例可直接修改）
3. 点击「开始评估」→ 右栏立即显示决策、分数与建议
4. 需要回溯时进入「历史记录」查看；「关于」可查看模型与隐私说明

## 4. 已知限制（如实声明）

- 模型基于**合成数据**训练（288 条 / 36 场景组），未在真实业务日志上验证；
  输出可参考，不可宣称真实业务准确率
- 跨组泛化时存在误判：例如训练集中不存在的授权组合（denied×file.delete）
  会被外推，必须靠独立策略引擎兜底
- 当前版本不含端侧 tokenizer 之外的文本预处理扩展；输入格式以表单字段为准
- 应用为 OpenHarmony 调试签名分发；正式分发需按企业签名流程重签

## 5. 构建、签名与安装（开发者）

```bash
bash harmony/scripts/build_hap.sh        # hvigor 构建（约 6–20s）
bash harmony/scripts/sign_hap.sh         # OpenHarmony 调试证书签名
bash harmony/scripts/install_run.sh <device_id>   # hdc 安装 + 启动 + 日志
```

模型转换（Windows/WSL）：

```bash
python scripts/make_probe_mlp.py          # M2-A 探针模型
bash harmony/scripts/convert_onnx_to_ms.sh models/risk_guard.onnx \
  harmony/entry/src/main/resources/rawfile/risk_guard
```
